# 00-inbox

## O que é esta pasta

Esta é a entrada geral do sistema. Ela funciona como uma sala de entrada para ideias, pensamentos, anotações, dúvidas, insights e lembretes que ainda não têm lugar claro.

## Para que ela serve

Serve para capturar rápido sem interromper seu fluxo. O objetivo é não perder a ideia só porque você ainda não sabe onde ela pertence.

## Quando usar

- Quando veio da sua cabeça e ainda está solto.
- Quando você quer registrar uma dúvida, insight, lembrete ou reflexão rapidamente.
- Quando a classificação ainda não está clara.
- Quando a ideia precisa ser processada depois pela IA.

## Quando não usar

- Não use para fontes brutas longas, como vídeos, PDFs, aulas e artigos; use `01-raw/`.
- Não use como lugar final de notas processadas.
- Não use para projetos ativos confirmados; use `05-projects/active/` somente depois de confirmação.
- Não use para criar exemplos como arquivos reais.

## O que colocar aqui

- Ideias rápidas.
- Pensamentos soltos.
- Dúvidas de estudo.
- Reflexões pessoais.
- Lembretes ainda sem contexto.
- Ideias de sistema ainda confusas.

## Exemplos de uso

- Exemplo conceitual: uma ideia rápida no meio do dia.
- Exemplo conceitual: uma frase que você quer guardar.
- Exemplo conceitual: uma dúvida sobre estudo.
- Exemplo conceitual: um pensamento sobre trabalho.
- Exemplo conceitual: uma reflexão pessoal.

## Como esta pasta se conecta com o resto do sistema

`00-inbox/` é o ponto de captura inicial. Depois, a IA pode mover ou conectar o conteúdo com `02-domains/`, `03-wiki/`, `05-projects/`, `07-reviews/` ou `99-archive/`, conforme o caso.

## Fluxo recomendado

1. Capture rapidamente.
2. Deixe em `00-inbox/`.
3. Depois peça para a IA processar.
4. A IA classifica e move ou conecta com a área correta.

## Regras importantes

- Capture primeiro, organize depois.
- Não transforme o inbox em arquivo permanente.
- Se for fonte externa, use `01-raw/`.
- Se houver dúvida, manter no inbox é melhor do que inventar classificação.

## Resumo rápido

Use `00-inbox/` quando veio da sua cabeça e você ainda não sabe onde colocar.
