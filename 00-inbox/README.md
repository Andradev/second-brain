# 00-inbox

## O que e esta pasta?

E a entrada manual para pensamentos soltos.

## Quando usar?

Use quando algo veio da sua cabeca e ainda esta baguncado.

## O que colocar aqui?

- ideias soltas
- duvidas
- anotacoes rapidas
- pensamentos
- insights
- reflexoes
- observacoes do trabalho
- coisas que pediram para fazer

## O que nao colocar aqui?

Nao coloque fontes externas inteiras, como artigos, PDFs, videos, transcricoes ou documentos. Isso vai para `01-fontes/inbox/`.

Nao tente criar projeto ativo direto daqui.

## Como a IA ajuda depois?

A IA le o que entrou, classifica, conecta com areas, identifica tarefas ou duvidas e move o que tiver base real para o lugar certo.

## Uso simples

Escreva em `notas-rapidas.md` ou crie arquivos soltos em `para-processar/`.
