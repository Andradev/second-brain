# Andrej Karpathy

AI researcher and public thinker referenced here as the originator of the LLM Wiki pattern used by this vault.

## Current Synthesis

Karpathy's LLM Wiki idea supplies the core architecture: raw sources, LLM-maintained wiki, schema rules, ingest/query/lint workflows, index, and log. Several YouTube sources explain or extend this pattern into second-brain, journal, CRM, and company-brain workflows.
