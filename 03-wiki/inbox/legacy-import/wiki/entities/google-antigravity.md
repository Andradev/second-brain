# Google Antigravity

IDE-like AI development environment referenced as a visual workspace for creating and iterating software projects with AI models.

## Current Synthesis

The Felipe Borges sources frame Antigravity as a visual control surface: it shows files, plans, prompts, generated code, and project state. It pairs well with stronger implementation agents such as Claude Code and can integrate with services like Supabase through MCP.
