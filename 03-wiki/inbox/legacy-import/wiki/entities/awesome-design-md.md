# awesome-design-md

Open-source repository of Markdown design-system files that can guide AI coding agents toward specific visual styles.

## Current Synthesis

The repository is presented as a way to improve AI-generated UI by giving agents brand-inspired design context. It is useful as a reusable `DESIGN.md` asset inside a project.
