# Model Aggregator Platforms

Model aggregator platforms provide one interface for accessing multiple AI models, usually by wrapping third-party model APIs behind a subscription, credit system, or user-provided API keys.

## Current Synthesis

[[wiki/sources/adapta-myhub-ou-inner-ai-qual-a-melhor|Adapta, MyHub ou Inner AI]] argues that subscription aggregators should be judged mainly by education, community, interface quality, and convenience. The underlying model access is not unique if it depends on third-party APIs.

The practical distinction is between unlimited/manual subscriptions, pay-per-use routers, and bring-your-own-key chat interfaces. Unlimited manual plans can work economically when users do not automate heavy usage; API-friendly pay-per-use tools are more appropriate for automation.
