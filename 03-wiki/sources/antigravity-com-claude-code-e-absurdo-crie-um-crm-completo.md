# Antigravity com Claude Code e Absurdo

Source path: `raw/processed/Antigravity com Claude Code É ABSURDO! Crie um CRM Completo (Muito Fácil).md`

Processed date: 2026-05-11

## Short Summary

Felipe Borges demonstrates a workflow that combines Google Antigravity as a visual project workspace with Claude Code as an implementation agent. The practical example is a CRM/task-management app where Gemini in Antigravity generates a polished interface, Claude Code adds behavior, and the result is tested and iterated through prompts.

## Key Claims Or Observations

- [[wiki/entities/google-antigravity|Google Antigravity]] is presented as the "cockpit": a visual IDE-like environment for navigating files, seeing plans, and using Gemini.
- [[wiki/entities/claude-code|Claude Code]] is presented as the "pilot": stronger for backend logic, database structure, complex code changes, and behavioral fixes.
- The workflow separates design generation from functional implementation: Gemini handles the first visual pass, Claude Code handles drag-and-drop, cards, columns, modals, and data-editing behavior.
- The creator recommends using stronger Claude models for more complex backend and data work, and using effort settings to balance speed and quality.
- Deployment is framed as a separate step that requires GitHub plus hosting and a security review before putting client data online.
