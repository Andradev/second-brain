# Agentic Coding Workflow

An agentic coding workflow delegates implementation work to AI coding agents while using human judgment, context files, specs, tests, and review to keep the system coherent.

## Current Synthesis

The sources converge on the idea that AI coding is strongest when the human supplies architecture, constraints, and verification. [[03-wiki/sources/antigravity-com-claude-code-e-absurdo-crie-um-crm-completo|Antigravity com Claude Code e Absurdo]] emphasizes tool division: visual IDE for orientation, stronger code agent for logic. [[03-wiki/sources/how-senior-engineers-actually-build-with-ai-in-2026|How Senior Engineers Actually Build With AI in 2026]] emphasizes specs, context folders, progress tracking, and feature-by-feature execution.

The recurring warning is that speed alone is fragile. Agents drift, forget decisions, and break boundaries unless the project gives them durable context.
