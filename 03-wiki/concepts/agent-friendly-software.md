# Agent-Friendly Software

Agent-friendly software is software designed so AI agents can operate it reliably through APIs, CLIs, MCP servers, documentation, skills, and machine-readable workflows.

## Current Synthesis

The idea appears most directly in [[03-wiki/sources/6-negocios-de-ia-que-ainda-nao-tem-concorrencia|6 Negocios de IA que Ainda Nao Tem Concorrencia]], where products increasingly need to serve agents as users, not only humans. Human-facing polish still matters, but agents need operational interfaces and explicit instructions.

The same pattern appears indirectly in [[03-wiki/sources/how-senior-engineers-actually-build-with-ai-in-2026|How Senior Engineers Actually Build With AI in 2026]], where tools like Clerk, Liveblocks, and Trigger.dev become more useful when they ship agent-facing docs, skills, SDK patterns, and integration affordances.
