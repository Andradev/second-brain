# Spec-Driven Agentic Development

Spec-driven agentic development is a workflow where an AI coding agent implements small, explicit feature specifications within a project that already has architecture, standards, and progress context.

## Current Synthesis

[[03-wiki/sources/how-senior-engineers-actually-build-with-ai-in-2026|How Senior Engineers Actually Build With AI in 2026]] is the main source. It argues that serious AI development needs the same discipline as senior engineering: design docs, boundaries, user flows, success criteria, coding standards, and progress tracking.

The pattern is:

- Put durable project context in files.
- Tell the agent to read those files before implementing.
- Break work into feature specs.
- Verify each feature.
- Update the progress tracker after each step.
