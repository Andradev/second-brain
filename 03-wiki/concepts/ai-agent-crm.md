# AI Agent CRM

An AI agent CRM is a customer or contact interface where AI-driven conversations, lead records, and message histories are captured, visible, searchable, and actionable.

## Current Synthesis

The strongest implementation source is [[03-wiki/sources/crie-um-agente-de-ia-no-whatsapp-com-crm|Crie um Agente de IA no WhatsApp com CRM]], which builds a WhatsApp agent with n8n, Z-API, Supabase, and an Antigravity-generated CRM. [[03-wiki/sources/build-a-second-brain-that-remembers-everything|Build A Second Brain That Remembers Everything]] uses CRM more personally, storing contacts and relationship memory inside a second brain.

Across both, the key insight is that agent conversations gain value when they become durable records rather than disappearing inside chat apps.
