# Obsidian As AI Frontend

Obsidian can act as the visual and navigational frontend for an AI-maintained Markdown knowledge base.

## Current Synthesis

The sources repeatedly use Obsidian as the place where humans inspect the wiki while an LLM maintains the files. Obsidian's value is local Markdown storage, links, graph view, and Web Clipper integration. The LLM does the summarizing, cross-linking, and synthesis; Obsidian makes the evolving structure visible.

This vault follows that pattern: the user can browse the wiki in Obsidian while Codex updates the Markdown files directly.
