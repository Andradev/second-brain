# 03-wiki/questions

## O que é esta pasta

Esta pasta guarda perguntas abertas que surgiram de conteúdo real.

## Para que ela serve

Esta subpasta ajuda a manter a wiki navegável, conectada e baseada em conteúdo real já capturado ou processado.

## Quando usar

- Quando o conteúdo já tiver base real no vault.
- Quando a informação precisar ser lembrada, conectada ou reutilizada.
- Quando a IA for solicitada a organizar conhecimento já existente.

## Quando não usar

- Não use para captura inicial.
- Não use para fonte bruta original.
- Não use para criar páginas fictícias, exemplos reais simulados ou placeholders como se fossem notas finais.

## O que colocar aqui

- Dúvidas recorrentes.
- Perguntas de estudo.
- Questões espirituais, profissionais ou pessoais com base real.
- Perguntas que merecem investigação futura.

## Exemplos de uso

- Exemplo conceitual: uma pergunta que apareceu em várias notas de estudo.
- Exemplo conceitual: uma dúvida surgida ao processar uma fonte.
- Exemplo conceitual: uma questão em aberto para revisão futura.

## Como esta pasta se conecta com o resto do sistema

A wiki recebe conhecimento extraído de `01-raw/`, organizado em `02-domains/` e conectado a mapas, projetos, revisões e outputs quando isso ajuda a reutilizar o conhecimento.

## Fluxo recomendado

1. Capture primeiro em `00-inbox/` ou `01-raw/`.
2. Processe a fonte ou nota em um domínio adequado.
3. Crie ou atualize a página da wiki apenas quando houver conteúdo real suficiente.
4. Conecte com notas, fontes, conceitos, entidades, projetos ou perguntas existentes.
5. Revise periodicamente para evitar páginas vazias ou duplicadas.

## Regras importantes

- Só crie páginas com base real.
- Não crie exemplos como arquivos.
- Prefira atualizar uma página existente a duplicar conhecimento.
- Use links internos quando a conexão for real.

## Resumo rápido

Use `03-wiki/questions/` para perguntas reais que ainda precisam de resposta.
