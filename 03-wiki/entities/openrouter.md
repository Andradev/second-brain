# OpenRouter

Model routing platform referenced as a pay-per-use alternative to subscription-based AI model aggregator platforms.

## Current Synthesis

The 1P Company source presents OpenRouter as useful because it supports pay-per-use model access and API usage, making costs visible and better suited to automation than unlimited manual chat subscriptions.
