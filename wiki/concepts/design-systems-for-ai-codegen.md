# Design Systems For AI Codegen

Design systems for AI codegen are structured design references, often in Markdown or code tokens, that guide AI agents toward consistent visual output.

## Current Synthesis

[[wiki/sources/awesome-design-md-55-design-systems-prontos-pro-claude-code|awesome-design-md]] presents the most direct example: `DESIGN.md` files extracted from strong brands and products can be given to Claude Code to produce better-looking landing pages and dashboards. [[wiki/sources/how-senior-engineers-actually-build-with-ai-in-2026|How Senior Engineers Actually Build With AI in 2026]] uses the same principle at a project level through UI context files, CSS tokens, and component constraints.

The shared claim is that agents need explicit aesthetic and component context. Otherwise they drift toward generic templates.
