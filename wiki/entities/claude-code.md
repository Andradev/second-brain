# Claude Code

AI coding agent referenced as a terminal or editor-integrated tool for implementing code changes from prompts and project context.

## Current Synthesis

Claude Code is repeatedly used as the implementation engine for agentic coding. In the Antigravity workflow, it handles complex logic and backend work. In the LLM Wiki workflow, it can maintain a Markdown vault. In the design-system workflow, it consumes `DESIGN.md` files to generate UI.
