# Sistema

Indice interno da parte tecnica do Second Brain.

## Modulos

- `agents/`: regras auxiliares para agentes.
- `llm-wiki/`: nucleo interno da LLM Wiki.
- `prompts/`: biblioteca de prompts.
- `templates/`: modelos reutilizaveis.
- `automacoes/`: rotinas futuras.
- `memoria-contextual/`: regras de memorias recorrentes.
- `evolucao/`: propostas de evolucao controlada.
- `regras/`: manuais, schemas e regras auxiliares.

## Uso

O usuario nao precisa navegar por esta pasta no dia a dia.

A IA consulta este modulo para organizar, conectar e manter conhecimento sem expor a complexidade tecnica na interface principal.
