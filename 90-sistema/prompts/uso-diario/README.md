# Prompts de uso diário

Esta pasta guarda os principais prompts para usar no dia a dia com o Second Brain.

A ideia é manter poucos prompts, simples e fáceis de copiar.

## Quando usar

Use estes prompts quando quiser pedir para a IA organizar o que você capturou.

## Prompts disponíveis

1. `01-processar-inbox.md`

Use quando quiser processar ideias, pensamentos, dúvidas, tarefas soltas e anotações rápidas que estão em `00-inbox/`.

2. `02-processar-fontes.md`

Use quando quiser processar fontes externas que estão em `01-fontes/inbox/`, como vídeos, artigos, PDFs, aulas, prints, documentos ou transcrições.

## Regra simples

Se veio da sua cabeça, vai para `00-inbox/`.

Se veio de fora, vai para `01-fontes/inbox/`.

Depois a IA organiza.

## Importante

Estes prompts são modelos reutilizáveis.

Eles não devem ser executados automaticamente apenas por existirem.
