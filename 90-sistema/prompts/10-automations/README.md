# Automações

## Objetivo

Prompts para documentar, criar e rodar rotinas de automação com segurança.

## Prompts

- [[create-automation-module|Criar módulo de automação]]
- [[run-daily-routine|Rodar rotina diária]]
- [[run-weekly-routine|Rodar rotina semanal]]
- [[run-monthly-maintenance|Rodar manutenção mensal]]
- [[generate-automation-report|Gerar relatório de automação]]

## Regras da categoria

- Automação nunca roda diretamente na main.
- Automação deve criar branch.
- Automação não faz merge automático.
- Automação não cria conteúdo simulado.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
