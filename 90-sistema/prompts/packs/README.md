# Prompt Packs

## Objetivo

Esta pasta guarda fluxos compostos que combinam prompts da Biblioteca de Prompts.

## Regra principal

Packs não executam nada automaticamente.

Eles apenas documentam uma sequência recomendada de prompts.

- [[context-memory-pack|Pack de memórias contextuais]]
- [[system-evolution-pack|Pack de evolução do sistema]]
- [[project-management-pack|Pack de gestão de projetos]]
- [[maintenance-pack|Pack de manutenção]]

## Como usar

1. Escolha o pack relacionado ao fluxo desejado.
2. Leia a sequência sugerida.
3. Execute apenas os prompts necessários e autorizados.
4. Pare para confirmação quando houver alteração real ou estrutural.
