# Manutenção

## Objetivo

Prompts para auditar estrutura, links, duplicidades e cobertura de README sem bagunçar conteúdo real.

## Prompts

- [[audit-vault-structure|Auditar estrutura do vault]]
- [[find-orphan-notes|Encontrar notas órfãs]]
- [[find-duplicate-concepts|Encontrar conceitos duplicados]]
- [[clean-empty-files|Limpar arquivos vazios]]
- [[check-index-links|Verificar links de índices]]
- [[check-readme-coverage|Verificar cobertura de README]]

## Regras da categoria

- Auditar antes de alterar.
- Não apagar conteúdo real.
- Pedir confirmação para correções destrutivas.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
