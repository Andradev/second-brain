# Context Memory

## Objetivo

Prompts para criar, consultar, atualizar e arquivar memórias contextuais por domínio.

## Prompts

- [[create-context-memory|Criar memória contextual]]
- [[consult-context-memories|Consultar memórias contextuais]]
- [[update-context-memory|Atualizar memória contextual]]
- [[archive-context-memory|Arquivar memória contextual]]
- [[suggest-context-memory|Sugerir memória contextual]]

## Regras da categoria

- Memórias ficam em `02-areas/[domínio]/memory/`.
- Memória contextual só nasce de pedido explícito ou evidência real de recorrência.
- Memória não é nota comum.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
