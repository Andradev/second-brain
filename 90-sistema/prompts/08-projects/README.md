# Projetos

## Objetivo

Prompts para analisar ideias de projeto, promover projetos confirmados e manter contexto, tarefas e decisões.

## Prompts

- [[analyze-project-idea|Analisar ideia de projeto]]
- [[promote-idea-to-project|Promover ideia a projeto]]
- [[create-project-structure|Criar estrutura de projeto]]
- [[update-project-context|Atualizar contexto do projeto]]
- [[update-project-tasks|Atualizar tarefas do projeto]]
- [[update-project-decisions|Atualizar decisões do projeto]]
- [[review-project-status|Revisar status do projeto]]

## Regras da categoria

- Não criar projeto ativo sem confirmação.
- Ideias ficam em `02-areas/ideias/` ou `03-projetos/inbox/`.
- Projeto ativo só vai para `03-projetos/ativos/` com confirmação.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
