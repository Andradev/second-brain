# Propostas de evolução

Esta pasta guarda propostas de evolução do Second Brain separadas por status.

## Estados

- `pending/`: propostas aguardando revisão humana.
- `accepted/`: propostas aprovadas pelo usuário.
- `rejected/`: propostas rejeitadas ou descartadas.
- `implemented/`: propostas já implementadas.

## Regra principal

Propostas reais devem se basear em evidências reais do vault ou em pedido explícito do usuário.

Não criar propostas simuladas.
