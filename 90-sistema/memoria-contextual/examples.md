# Exemplos conceituais de Context Memories

Este arquivo mostra situações conceituais em que uma Context Memory poderia ser criada.

Não transforme estes exemplos em memórias reais.

## Uso técnico

Uma memória pode registrar que, antes de executar uma aplicação específica, existe um procedimento recorrente que deve ser lembrado.

## Trabalho

Uma memória pode guardar uma regra recorrente de trabalho que precisa ser considerada antes de responder sobre determinado processo.

## Estudos

Uma memória pode registrar uma preferência de estudo que deve ser aplicada quando o usuário pedir ajuda sobre uma disciplina ou tema recorrente.

## Saúde

Uma memória pode guardar um cuidado recorrente informado pelo usuário, desde que venha de conteúdo real e pedido explícito.

## Finanças

Uma memória pode lembrar uma regra prática que o usuário deseja considerar sempre que falar sobre decisões financeiras.

## Regra de uso

Os exemplos acima são apenas conceituais.

Memórias reais só devem ser criadas a partir de informação real do usuário, conteúdo real existente no vault ou pedido explícito.
