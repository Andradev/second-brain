# Vida pessoal

Area para diario, saude, financas, relacionamentos, rotina e decisoes.

Ela junta temas pessoais que podem crescer com o tempo. Se uma subarea ficar grande demais, a IA deve propor uma evolucao antes de reorganizar.

Subpastas:

- `diario/`
- `saude/`
- `financas/`
- `relacionamentos/`
- `rotina/`
- `decisoes/`
