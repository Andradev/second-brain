# Trabalho

Area para processos, regras de negocio, tarefas, duvidas, aprendizados e sistemas do trabalho.

Use esta area para conhecimento ja minimamente organizado. Capturas soltas ainda vao para `00-inbox/`; documentos originais da empresa vao para `01-fontes/inbox/`.

Subpastas:

- `processos/`: como as coisas funcionam.
- `regras-de-negocio/`: regras, validacoes, permissoes, fluxos e comportamentos.
- `tarefas/`: coisas que pediram para fazer.
- `duvidas/`: perguntas abertas do trabalho.
- `aprendizados/`: aprendizados profissionais.
- `sistemas/`: notas sobre sistemas especificos.
