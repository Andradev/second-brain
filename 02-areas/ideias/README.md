# Ideias

Area para ideias que ja foram minimamente organizadas ou agrupadas.

Ideia solta vai primeiro para `00-inbox/`.

Fluxo:

1. Ideia solta em `00-inbox/`.
2. IA organiza em `02-areas/ideias/agrupadas/`.
3. Ideia amadurecida vai para `03-projetos/inbox/`.
4. Projeto confirmado vai para `03-projetos/ativos/`.

Subpastas:

- `agrupadas/`
- `avaliadas/`
- `descartadas/`
