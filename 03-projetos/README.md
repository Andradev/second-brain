# 03-projetos

## O que e esta pasta?

E a area de projetos reais ou candidatos claros.

## Quando usar?

Use quando uma ideia ja tem forma de projeto ou quando o projeto foi confirmado.

## O que colocar aqui?

- ideias quase prontas para virar projeto
- projetos ativos confirmados
- projetos pausados
- projetos concluidos

## O que nao colocar aqui?

Nao coloque qualquer ideia solta aqui. Ideia solta vai para `00-inbox/`.

Nao crie projeto ativo sem confirmacao.

## Estrutura

- `inbox/`: candidatos a projeto.
- `ativos/`: projetos confirmados.
- `pausados/`: projetos parados temporariamente.
- `concluidos/`: projetos finalizados.

## Como a IA ajuda depois?

A IA pode amadurecer ideias, organizar contexto, levantar proximos passos e manter decisoes do projeto, mas projeto ativo exige confirmacao do usuario.
