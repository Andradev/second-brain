# 06-outputs/prompts

## O que é esta pasta

Esta pasta guarda prompts finais e reutilizáveis.

## Para que ela serve

Esta subpasta guarda materiais prontos para reutilização, envio, consulta, estudo ou apresentação.

## Quando usar

- Quando o material já for uma saída final ou reutilizável.
- Quando a IA gerar um documento, resumo, guia, prompt, e-mail, relatório ou apresentação solicitado pelo usuário.
- Quando o conteúdo precisar ficar separado das fontes brutas e das notas de trabalho.

## Quando não usar

- Não use para fonte original não processada; use `01-raw/`.
- Não use para notas de domínio ainda em construção; use `02-domains/`.
- Não use para conhecimento conectado de longo prazo; use `03-wiki/` quando for o caso.

## O que colocar aqui

- Prompts de revisão.
- Prompts de processamento.
- Prompts para geração de outputs.
- Instruções reutilizáveis para conversas com IA.

## Exemplos de uso

- Exemplo conceitual: prompt para revisar a semana.
- Exemplo conceitual: prompt para processar uma fonte bruta.
- Exemplo conceitual: prompt para transformar notas em guia.

## Como esta pasta se conecta com o resto do sistema

Outputs podem nascer de fontes em `01-raw/`, notas em `02-domains/`, conhecimento em `03-wiki/`, projetos em `05-projects/` ou revisões em `07-reviews/`.

## Fluxo recomendado

1. Defina que tipo de saída você precisa.
2. Peça para a IA gerar ou organizar o material com base em conteúdo real.
3. Salve a saída na subpasta correta.
4. Conecte com o projeto, domínio, fonte ou wiki que originou o material.
5. Atualize o material quando ele deixar de representar a versão atual.

## Regras importantes

- Outputs não substituem a fonte original.
- Quando o output depender de fontes, preserve ou cite os caminhos usados.
- Não use outputs para simular conhecimento que não existe no vault.
- Se ficar obsoleto, mova ou conecte com `99-archive/`.

## Resumo rápido

Use `06-outputs/prompts/` para prompts prontos para reutilizar.
