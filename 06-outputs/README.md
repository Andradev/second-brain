# 06-outputs

## O que é esta pasta

Esta pasta guarda materiais finais ou reutilizáveis gerados pelo usuário ou pela IA.

## Para que ela serve

Serve para separar resultados prontos de fontes brutas, notas de trabalho e conhecimento conectado.

## Quando usar

- Quando um material está pronto para reutilizar, enviar, estudar ou consultar.
- Quando a IA gerar um documento, resumo, guia, prompt, e-mail, relatório ou apresentação.
- Quando uma saída precisa ficar preservada como entrega.

## Quando não usar

- Não use para fonte original; use `01-raw/`.
- Não use para nota de área da vida; use `02-domains/`.
- Não use para conhecimento conectado; use `03-wiki/`.
- Não use para rascunhos sem valor final.

## O que colocar aqui

- Documentos.
- Resumos.
- Guias de estudo.
- Prompts.
- E-mails.
- Relatórios.
- Apresentações.

## Exemplos de uso

- Exemplo conceitual: um guia de estudo gerado a partir de notas reais.
- Exemplo conceitual: um relatório final de uma revisão do vault.
- Exemplo conceitual: um e-mail pronto para enviar.

## Como esta pasta se conecta com o resto do sistema

Outputs podem nascer de `01-raw/`, `02-domains/`, `03-wiki/`, `05-projects/` e `07-reviews/`. Eles são o resultado final, não a origem nem a base de conhecimento.

## Fluxo recomendado

1. Defina o tipo de saída desejada.
2. Peça para a IA gerar com base em conteúdo real ou pedido explícito.
3. Salve na subpasta adequada.
4. Conecte com projetos, domínios, fontes ou wiki quando fizer sentido.
5. Arquive outputs antigos quando deixarem de ser úteis.

## Regras importantes

- Outputs são resultados finais, não fontes brutas.
- Preserve fontes originais em `01-raw/`.
- Não gere conteúdo fictício para preencher pasta.
- Quando houver base real, indique de onde veio.

## Resumo rápido

Use `06-outputs/` para materiais prontos para reutilizar, enviar, estudar ou consultar.
