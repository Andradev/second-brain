# 01-raw/inbox

## O que é esta pasta

Esta é a entrada geral de fontes brutas ainda sem categoria clara.

## Para que ela serve

Serve para guardar rapidamente uma fonte externa quando você ainda não decidiu se ela é artigo, vídeo, aula, reunião, material de trabalho ou outro tipo.

## Quando usar

- Quando a fonte é externa, mas a categoria ainda não está clara.
- Quando você quer preservar o material agora e classificar depois.
- Quando a IA deve decidir a categoria correta ao processar.

## Quando não usar

- Não use para ideias soltas pessoais; use `00-inbox/`.
- Não use para notas processadas.
- Não use para fontes que já têm categoria óbvia; coloque direto no `inbox/` da categoria.

## O que colocar aqui

- Fontes brutas sem categoria definida.
- Materiais importados que precisam de triagem.
- Conteúdos externos aguardando classificação.

## Exemplos de uso

- Exemplo conceitual: um material salvo rapidamente sem saber se é artigo, aula ou referência.
- Exemplo conceitual: um conjunto de arquivos importados que precisa de triagem.
- Exemplo conceitual: uma fonte externa cuja utilidade ainda não está clara.

## Como esta pasta se conecta com o resto do sistema

Depois da triagem, a fonte deve ir para o `inbox/` da categoria correta. Quando processada, pode gerar notas em `02-domains/` e páginas em `03-wiki/`.

## Fluxo recomendado

1. Coloque a fonte em `01-raw/inbox/`.
2. Peça para a IA classificar quando houver tempo.
3. A IA move a fonte para a categoria correta.
4. Depois, a fonte pode ser processada e ir para `processed/` da categoria.

## Regras importantes

- Esta pasta é de triagem, não de armazenamento final.
- Preserve o conteúdo original.
- Se houver dúvida, não apague; mantenha para revisão.
- Não crie notas simuladas a partir de exemplos.

## Resumo rápido

Use `01-raw/inbox/` para fontes externas ainda sem categoria clara.
