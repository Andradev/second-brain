# 01-raw/images

## O que é esta pasta

Esta pasta guarda imagens e prints usados como fontes brutas.

## Para que ela serve

Esta pasta separa fontes brutas por tipo, mantendo a origem preservada antes de qualquer nota processada ser criada.

## Quando usar

- Quando a fonte já tiver esta categoria clara.
- Quando você quiser guardar o material original antes de pedir processamento.
- Quando a IA precisar encontrar rapidamente fontes desse tipo.

## Quando não usar

- Não use para notas processadas, conclusões pessoais ou sínteses finais.
- Não use para ideias soltas que vieram apenas da sua cabeça; nesse caso use `00-inbox/`.
- Não use para conhecimento conectado e reutilizável; esse conteúdo pertence a `03-wiki/` depois de processado.

## O que colocar aqui

- Prints.
- Imagens de referência.
- Capturas de tela.
- Material visual que precisa ser preservado.

## Exemplos de uso

- Exemplo conceitual: um print com informação importante.
- Exemplo conceitual: uma imagem de referência para estudo.
- Exemplo conceitual: captura visual que pode gerar nota depois.

## Como esta pasta se conecta com o resto do sistema

A fonte entra em `inbox/`, é preservada em sua forma original e, quando processada, pode gerar notas em `02-domains/`, páginas em `03-wiki/`, saídas em `06-outputs/` ou pendências em `07-reviews/`.

## Fluxo recomendado

1. Coloque a fonte nova em `inbox/`.
2. Peça para a IA processar quando quiser extrair conhecimento real.
3. Depois do processamento, mantenha a fonte original em `processed/` da própria categoria.
4. Use `archive/` para fontes antigas, duplicadas, pausadas ou que não serão usadas agora.
5. Confira se as notas derivadas citam ou apontam para a fonte original.

## Regras importantes

- `inbox/` guarda fontes ainda não processadas.
- `processed/` guarda fontes já analisadas pela IA.
- `archive/` guarda fontes que não estão ativas, mas não devem ser apagadas.
- A IA não deve reescrever a fonte bruta.
- Nenhuma nota derivada deve ser criada se não houver conteúdo real na fonte.

## Resumo rápido

Use `01-raw/images/` para imagens e prints preservados.
