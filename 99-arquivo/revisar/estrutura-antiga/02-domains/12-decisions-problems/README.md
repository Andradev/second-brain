# 12-decisions-problems

## O que é esta pasta

Este domínio é para decisões importantes, problemas recorrentes, análises, trade-offs, riscos, opções e aprendizados.

## Para que ela serve

Este domínio organiza conteúdos por contexto humano. Ele ajuda a separar o que pertence a esta área da vida sem transformar tudo imediatamente em projeto ou página de wiki.

## Quando usar

- Quando uma nota já pertence claramente a este tema.
- Quando uma fonte processada gerar aprendizados ou registros ligados a esta área.
- Quando houver perguntas, decisões, padrões ou sínteses recorrentes dentro deste domínio.

## Quando não usar

- Não use como entrada geral de ideias soltas; use `00-inbox/` quando ainda estiver confuso.
- Não use para guardar fonte bruta original; use `01-raw/`.
- Não use para criar projeto ativo sem confirmação do usuário; use `05-projects/inbox/` até existir confirmação.
- Não crie arquivos apenas para demonstrar exemplos.

## O que colocar aqui

- Decisões em análise ou já tomadas.
- Problemas recorrentes.
- Mapas de opções, riscos e trade-offs.
- Aprendizados derivados de decisões.
- `inbox/`: notas da área ainda não organizadas.
- `notes/`: notas processadas e úteis dentro do domínio.
- `sources/`: referências específicas da área depois de conectadas ao domínio.
- `concepts/`: conceitos importantes que nasceram de conteúdo real da área.
- `entities/`: pessoas, ferramentas, organizações, personagens ou elementos reais mencionados em conteúdo real.
- `questions/`: perguntas abertas que surgiram de notas ou fontes reais.
- `synthesis/`: sínteses vivas quando já existe material suficiente.
- `decisions/`: decisões tomadas ou em análise.
- `projects/`: projetos relacionados ao domínio, sem substituir `05-projects/` quando o projeto for central.

## Exemplos de uso

- Exemplo conceitual: uma decisão importante que precisa comparar opções.
- Exemplo conceitual: um problema recorrente que aparece em revisões.
- Exemplo conceitual: uma análise de riscos antes de agir.

## Como esta pasta se conecta com o resto do sistema

Decisions & Problems se conecta com todos os domínios quando uma área exige escolha, com Projects quando afeta execução, com Wiki quando gera princípios reutilizáveis e com Reviews para acompanhar pendências.

## Fluxo recomendado

1. Capture rapidamente em `00-inbox/` ou no `inbox/` deste domínio quando a área já estiver clara.
2. Peça para a IA classificar e processar o conteúdo.
3. A IA cria ou atualiza notas em `notes/` e preserva links para fontes quando houver.
4. Se aparecer um conceito, entidade, pergunta, decisão ou síntese real, a IA pode atualizar a subpasta adequada.
5. Quando o tema se tornar reutilizável fora do domínio, a IA pode conectar com `03-wiki/`.
6. Quando virar execução, o conteúdo pode se conectar a `05-projects/`.

## Regras importantes

- Antes de processar conteúdo deste domínio, a IA deve considerar o `_manual.md` do domínio.
- Não crie notas, conceitos, entidades, perguntas, sínteses, decisões ou projetos sem conteúdo real ou pedido explícito.
- Use `[[wikilinks]]` para conectar conteúdos reais quando houver base suficiente.
- Mantenha o domínio como contexto de vida; conhecimento reutilizável pode ser refletido na wiki depois.
- Diferencie fatos, inferências e dúvidas antes de registrar uma decisão.

## Resumo rápido

Use este domínio para organizar esta área da vida. Não use para fonte bruta, exemplo fictício ou projeto ativo sem confirmação. Depois a IA pode processar, conectar e sintetizar o que for real.
