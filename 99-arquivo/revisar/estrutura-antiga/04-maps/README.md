# 04-maps

## O que é esta pasta

Mapas são páginas de visão geral. Eles servem para enxergar o todo e navegar pelo próprio conhecimento.

## Para que ela serve

Servem para orientar a navegação pela vida, estudos, espiritualidade, carreira, projetos e relacionamentos sem guardar todos os detalhes em um único lugar.

## Quando usar

- Quando você quer visão geral de uma área.
- Quando precisa navegar por temas conectados.
- Quando uma revisão mostra padrões que merecem aparecer em um mapa.
- Quando a IA for solicitada a atualizar uma visão geral com base real.

## Quando não usar

- Não use para capturar notas soltas.
- Não use para fonte bruta.
- Não use como wiki detalhada.
- Não use para inventar áreas, projetos ou relações sem conteúdo real.

## O que colocar aqui

- `mapa-da-minha-vida.md`: visão geral das áreas da vida.
- `mapa-de-estudos.md`: visão dos estudos, cursos, dificuldades e progresso.
- `mapa-profissional.md`: visão de carreira, trabalho e crescimento profissional.
- `mapa-espiritual.md`: visão de fé, Bíblia, devocionais, valores e temas espirituais.
- `mapa-de-projetos.md`: visão dos projetos, ideias e iniciativas.
- `mapa-de-relacionamentos.md`: visão de pessoas importantes e conexões.

## Exemplos de uso

- Exemplo conceitual: usar um mapa para ver quais áreas da vida estão recebendo atenção.
- Exemplo conceitual: atualizar o mapa de estudos após uma revisão semanal.
- Exemplo conceitual: consultar o mapa de projetos antes de decidir próximos passos.

## Como esta pasta se conecta com o resto do sistema

Mapas apontam para `02-domains/`, `03-wiki/`, `05-projects/`, `07-reviews/` e outputs importantes. Eles ajudam a encontrar o caminho, mas não substituem as notas detalhadas.

## Fluxo recomendado

1. Capture e processe conteúdos nas áreas corretas.
2. Quando houver padrão ou visão geral útil, peça para a IA atualizar o mapa.
3. Use mapas para navegar e decidir onde aprofundar.
4. Mantenha cada mapa curto, útil e conectado.
5. Revise mapas periodicamente.

## Regras importantes

- Mapas mostram o todo, não todos os detalhes.
- Não criar mapas baseados em exemplos fictícios.
- Links devem apontar para conteúdos reais ou estruturas reais.
- Se o mapa ficar grande demais, ele precisa ser reorganizado.

## Resumo rápido

Use mapas para enxergar o todo, não para guardar tudo.
