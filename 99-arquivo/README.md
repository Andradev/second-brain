# 99-arquivo

## O que e esta pasta?

E a area para coisas antigas, pausadas, descartadas ou incertas.

## Quando usar?

Use quando algo nao deve ficar ativo, mas tambem nao deve ser apagado.

## O que colocar aqui?

- conteudo antigo
- projetos pausados fora da area ativa
- materiais descartados
- conteudo incerto
- estruturas antigas preservadas para revisao

## O que nao colocar aqui?

Nao use como inbox principal.

Ideias soltas vao para `00-inbox/`.

Fontes externas vao para `01-fontes/inbox/`.

## Estrutura

- `revisar/`: coisas incertas ou que precisam de decisao.
- `antigo/`: conteudo antigo preservado.
- `pausado/`: conteudo pausado.
- `descartado/`: conteudo descartado, mas preservado.

## Como a IA ajuda depois?

A IA pode revisar esta pasta, sugerir o que recuperar, mover ou manter arquivado, sem apagar conteudo real sem pedido.
