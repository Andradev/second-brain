# 01-raw

## O que é esta pasta

Esta pasta guarda fontes brutas e originais. Fonte bruta é qualquer conteúdo que vem de fora ou que deve ser preservado antes de virar conhecimento processado.

## Para que ela serve

Serve para manter a origem intacta. A fonte fica preservada aqui enquanto a IA cria notas processadas, conexões e sínteses em outras áreas.

## Quando usar

- Quando você salvar vídeos, transcrições, artigos, PDFs, livros, aulas, prints, reuniões ou documentos.
- Quando o conteúdo veio de uma fonte externa.
- Quando o material precisa ser preservado antes de virar nota processada.
- Quando a categoria da fonte ainda não estiver clara.

## Quando não usar

- Não use para ideias soltas que vieram da sua cabeça; use `00-inbox/`.
- Não use para notas processadas; elas pertencem a `02-domains/`.
- Não use para conhecimento conectado final; isso pertence a `03-wiki/`.
- Não reescreva a fonte original.

## O que colocar aqui

- Vídeos e transcrições.
- Artigos e PDFs.
- Livros e trechos preservados.
- Aulas e materiais de curso.
- Prints e imagens de referência.
- Reuniões e documentos de trabalho.
- Estudos bíblicos e materiais de referência.

## Exemplos de uso

- Exemplo conceitual: se você capturar uma transcrição de vídeo, coloque em `01-raw/videos/inbox/`.
- Exemplo conceitual: se você salvar um artigo para processar depois, coloque em `01-raw/articles/inbox/`.
- Exemplo conceitual: se a categoria ainda não estiver clara, coloque em `01-raw/inbox/`.

## Como esta pasta se conecta com o resto do sistema

`01-raw/` guarda a fonte original. `02-domains/` guarda a nota processada dentro de uma área da vida. `03-wiki/` guarda o conhecimento conectado gerado a partir das fontes.

## Fluxo recomendado

1. Nova fonte entra em `01-raw/inbox/`.
2. Se a categoria já for clara, ela pode entrar diretamente no `inbox/` da categoria.
3. A IA processa a fonte quando solicitada.
4. A fonte bruta vai para `processed/` da própria categoria.
5. O conhecimento extraído vai para `02-domains/` e `03-wiki/`.

## Regras importantes

- Cada categoria usa `inbox/`, `processed/` e `archive/`.
- Não usar `01-raw/processed/` global.
- A fonte original deve ser preservada.
- Arquivos duplicados, antigos ou pouco úteis podem ir para `archive/` da categoria.
- Só crie notas derivadas a partir de conteúdo real.

## Resumo rápido

Use `01-raw/` quando o conteúdo veio de uma fonte externa e precisa ser preservado.
