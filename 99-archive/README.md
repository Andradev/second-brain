# 99-archive

## O que é esta pasta

Esta pasta guarda conteúdos antigos, pausados, substituídos, incertos ou que precisam de revisão.

## Para que ela serve

Serve para evitar apagar coisas importantes. Arquivar tira o conteúdo da área ativa sem destruir o histórico.

## Quando usar

- Quando algo não deve ficar ativo, mas também não deve ser apagado.
- Quando uma estrutura foi substituída.
- Quando um projeto, output ou nota ficou antigo.
- Quando há dúvida sobre a origem ou validade de um conteúdo.

## Quando não usar

- Não use como lixeira para apagar sem pensar.
- Não use para esconder conteúdo que ainda precisa ser processado.
- Não use para fontes novas.
- Não use para projetos ativos.

## O que colocar aqui

- `old-structures/`: estruturas antigas.
- `inactive-projects/`: projetos inativos.
- `deprecated-notes/`: notas substituídas.
- `old-outputs/`: saídas antigas.
- `review-needed/`: arquivos que precisam de revisão manual.

## Exemplos de uso

- Exemplo conceitual: uma estrutura antiga preservada por segurança.
- Exemplo conceitual: uma nota substituída por versão melhor.
- Exemplo conceitual: um arquivo incerto que precisa de revisão manual.

## Como esta pasta se conecta com o resto do sistema

`99-archive/` recebe conteúdos que saem de `02-domains/`, `03-wiki/`, `05-projects/`, `06-outputs/` ou estruturas antigas. Ele preserva contexto sem manter tudo ativo.

## Fluxo recomendado

1. Identifique por que o conteúdo não deve ficar ativo.
2. Escolha a subpasta de arquivo correta.
3. Mova preservando o conteúdo útil.
4. Registre motivo quando a mudança for relevante.
5. Revise `review-needed/` periodicamente.

## Regras importantes

- Arquivar não é apagar.
- Se houver dúvida, preserve.
- Conteúdo incerto deve ir para `review-needed/`.
- Não recrie conteúdo simulado a partir do arquivo.

## Resumo rápido

Use `99-archive/` para guardar com segurança o que não está mais ativo.
