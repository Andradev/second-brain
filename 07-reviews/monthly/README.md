# 07-reviews/monthly

## O que é esta pasta

Esta pasta guarda revisões de frequência mensal.

## Para que ela serve

Ela ajuda a transformar acúmulo de notas em percepção, próximos passos e decisões melhores.

## Quando usar

- Quando chegar o momento de revisar o período correspondente.
- Quando você quiser identificar padrões, pendências e aprendizados.
- Quando a IA for solicitada a resumir movimentos reais do vault.

## Quando não usar

- Não use para captura solta do dia a dia.
- Não use para fonte bruta original.
- Não use para inventar progresso, padrões ou decisões que não apareceram no vault.

## O que colocar aqui

- Revisões do período.
- Padrões percebidos.
- Pendências e perguntas abertas.
- Projetos parados ou avançando.
- Decisões e próximos passos.

## Exemplos de uso

- Exemplo conceitual: quais áreas avançaram neste mês?
- Exemplo conceitual: que padrões continuam aparecendo?
- Exemplo conceitual: que projeto, estudo ou decisão merece foco no próximo mês?

## Como esta pasta se conecta com o resto do sistema

As revisões olham para `00-inbox/`, `02-domains/`, `03-wiki/`, `05-projects/` e `06-outputs/`, e podem sugerir atualizações em mapas ou sínteses.

## Fluxo recomendado

1. Reúna o período que será revisado.
2. Peça para a IA analisar conteúdos reais do vault.
3. Registre padrões, pendências e próximos passos.
4. Atualize mapas, projetos ou perguntas quando fizer sentido.
5. Use a revisão seguinte para verificar continuidade.

## Regras importantes

- Revisão não é só resumo; ela deve gerar clareza.
- Não invente eventos ou aprendizados.
- Registre dúvidas reais como pendências.
- Conecte com projetos, domínios e mapas quando houver relação.

## Resumo rápido

Use `07-reviews/monthly/` para visão mensal e ajustes de direção.
