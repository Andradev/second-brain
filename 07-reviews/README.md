# 07-reviews

## O que é esta pasta

Esta pasta guarda revisões periódicas. Revisões servem para perceber padrões, ideias recorrentes, projetos parados, perguntas abertas, decisões pendentes e próximos passos.

## Para que ela serve

Serve para processar a vida e não se perder. A revisão não é só resumo; ela transforma conteúdo acumulado em clareza.

## Quando usar

- Quando quiser revisar um dia, semana, mês ou trimestre.
- Quando o vault estiver acumulando notas e precisar de síntese.
- Quando quiser identificar padrões, pendências e próximos passos.
- Quando a IA for solicitada a analisar conteúdos reais do período.

## Quando não usar

- Não use para captura solta.
- Não use para fontes brutas.
- Não use para inventar acontecimentos ou progresso.
- Não use como substituto de domínios, wiki ou projetos.

## O que colocar aqui

- `daily/`: revisões diárias.
- `weekly/`: revisões semanais.
- `monthly/`: revisões mensais.
- `quarterly/`: revisões trimestrais.

## Exemplos de uso

- Exemplo conceitual: observar o que apareceu muito esta semana.
- Exemplo conceitual: identificar ideias repetidas.
- Exemplo conceitual: perceber um projeto parado.
- Exemplo conceitual: notar uma decisão ainda aberta.

## Como esta pasta se conecta com o resto do sistema

Revisões consultam `00-inbox/`, `02-domains/`, `03-wiki/`, `05-projects/` e `06-outputs/`. Elas podem gerar atualizações em mapas, perguntas, sínteses e próximos passos.

## Fluxo recomendado

1. Escolha o período.
2. Peça para a IA analisar conteúdos reais relevantes.
3. Registre padrões, pendências, decisões e próximos passos.
4. Atualize mapas, projetos, perguntas ou sínteses quando necessário.
5. Use a próxima revisão para acompanhar continuidade.

## Regras importantes

- Revisão deve gerar clareza.
- Não inventar eventos.
- Distinguir fato, inferência e pendência.
- Conectar com áreas relevantes.

## Resumo rápido

Use `07-reviews/` para olhar para trás, encontrar padrões e decidir próximos passos.
