# Manual do projeto: Pulpito Web

## Proposito

Organizar contexto, tarefas, decisoes, fontes e entregaveis do projeto Pulpito Web.

## Como a IA deve atuar

- Conectar aprendizados de programacao com o projeto.
- Registrar decisoes tecnicas em `decisions.md`.
- Registrar tarefas em `tasks.md`.
- Manter `context.md` atualizado com objetivo, escopo e historico quando houver fontes reais.
