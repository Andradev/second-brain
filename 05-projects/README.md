# 05-projects

## O que é esta pasta

Esta pasta guarda projetos reais ou candidatos a projeto. Um projeto só deve virar ativo quando o usuário pedir ou confirmar.

## Para que ela serve

Serve para separar execução real de ideias soltas. Ela ajuda a acompanhar contexto, tarefas, decisões, fontes e outputs de iniciativas concretas.

## Quando usar

- Quando uma ideia está quase virando projeto.
- Quando um projeto foi confirmado pelo usuário.
- Quando um projeto precisa ser pausado, concluído ou arquivado.
- Quando decisões e tarefas precisam ficar ligadas a uma iniciativa.

## Quando não usar

- Não crie projetos automaticamente.
- Não use para ideias ainda muito vagas; use `02-domains/05-projects-ideas/`.
- Não use para notas pessoais soltas.
- Não use para outputs finais; use `06-outputs/`.

## O que colocar aqui

- `inbox/`: ideias que talvez virem projeto.
- `active/`: projetos ativos confirmados.
- `paused/`: projetos pausados.
- `completed/`: projetos concluídos.
- `archived/`: projetos antigos ou abandonados.

## Exemplos de uso

- Exemplo conceitual: uma ideia que já tem objetivo, mas ainda não foi confirmada.
- Exemplo conceitual: um projeto ativo confirmado pelo usuário.
- Exemplo conceitual: uma iniciativa pausada que precisa manter contexto.

## Como esta pasta se conecta com o resto do sistema

`02-domains/05-projects-ideas/` guarda ideias e brainstorms. `05-projects/inbox/` guarda ideias quase virando projeto. `05-projects/active/` guarda projetos confirmados. Projetos podem se conectar a domínios, wiki, fontes, decisões e outputs.

## Fluxo recomendado

1. Ideia aparece.
2. Vai para `02-domains/05-projects-ideas/` ou `05-projects/inbox/`.
3. Usuário decide se vira projeto.
4. Se confirmado, criar pasta em `05-projects/active/`.
5. Projeto ativo pode ter contexto, tarefas, decisões, fontes e outputs.

## Regras importantes

- Não criar projetos automaticamente.
- Projeto ativo exige pedido ou confirmação.
- Preserve decisões e contexto ao mover projetos.
- Arquivar não é apagar.
- Conecte projetos com outputs, domínios e wiki quando houver relação real.

## Resumo rápido

Use `05-projects/` somente para projetos reais ou candidatos claros.
