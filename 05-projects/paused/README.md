# 05-projects/paused

## O que é esta pasta

Esta pasta guarda projetos pausados, mas não encerrados.

## Para que ela serve

Esta subpasta ajuda a separar ideias candidatas, projetos ativos e projetos que mudaram de estado ao longo do tempo.

## Quando usar

- Quando o projeto confirmado não está em execução agora.
- Quando o usuário decide pausar sem abandonar.
- Quando o contexto precisa ser preservado para retomada.

## Quando não usar

- Não use para criar projetos fictícios.
- Não use para notas soltas sem intenção clara de projeto; nesse caso use `00-inbox/` ou `02-domains/05-projects-ideas/`.
- Não use para guardar outputs finais; eles pertencem a `06-outputs/`.

## O que colocar aqui

- Contexto do projeto ou da ideia, quando existir.
- Tarefas, decisões, riscos e próximos passos.
- Links para fontes, domínios, wiki e outputs relacionados.
- Registros de mudança de estado do projeto.

## Exemplos de uso

- Exemplo conceitual: um projeto ativo suspenso temporariamente.
- Exemplo conceitual: uma iniciativa aguardando tempo, recursos ou decisão.
- Exemplo conceitual: um projeto que pode voltar depois.

## Como esta pasta se conecta com o resto do sistema

Projetos podem nascer de `00-inbox/`, amadurecer em `02-domains/05-projects-ideas/`, virar candidatos em `05-projects/inbox/`, receber conhecimento de `03-wiki/` e gerar materiais finais em `06-outputs/`.

## Fluxo recomendado

1. Registre a ideia ou projeto no estado correto.
2. Se houver decisão importante, registre junto do contexto.
3. Conecte com domínio, wiki, fonte ou output quando houver relação real.
4. Mova para outra subpasta apenas quando o estado mudar de verdade.
5. Peça para a IA revisar tarefas, riscos e próximos passos quando necessário.

## Regras importantes

- Projeto ativo exige confirmação do usuário.
- Mudanças de estado devem preservar contexto útil.
- Decisões e tarefas devem nascer de intenção real, não de exemplos.
- Arquivar não é apagar; é retirar da área ativa.

## Resumo rápido

Use `05-projects/paused/` para projetos pausados com chance de retomada.
