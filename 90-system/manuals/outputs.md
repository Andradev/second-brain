# Manual: Outputs

## Proposito

`06-outputs/` guarda saidas finais ou reutilizaveis geradas pela IA.

## Subpastas

- `documents/`
- `summaries/`
- `study-guides/`
- `prompts/`
- `emails/`
- `reports/`
- `presentations/`

## Regras

- Nao colocar fonte bruta aqui.
- Se a saida estiver ligada a projeto, criar link no projeto.
- Se a saida gerar conceitos importantes, atualizar `03-wiki/`.
