# Manual: Relationships & CRM

## Proposito

Manual operacional resumido para [[02-domains/06-relationships-crm/index|Relationships & CRM]].

## Processamento

Criar ou atualizar entidades para pessoas relevantes.

Para cada pessoa importante, registrar:

- Nome
- Relacao com o usuario
- Contexto
- Projetos relacionados
- Conversas importantes
- Proximos passos

## Conexoes frequentes

- Trabalho
- Igreja
- Faculdade
- Projetos
- Diario pessoal
