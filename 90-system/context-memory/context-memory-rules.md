# Regras de Context Memories

## 1. O que é uma memória contextual

Uma memória contextual é uma informação recorrente que deve ser lembrada quando determinado assunto, domínio, projeto, tecnologia, pessoa ou situação aparecer novamente.

## 2. Quando criar uma memória

Criar uma memória quando o usuário disser coisas como:

- “Sempre que eu for fazer X, lembre disso.”
- “Toda vez que falarmos sobre Y, considere isso.”
- “Não posso esquecer que...”
- “Isso é importante para quando eu estiver mexendo em...”
- “Quando eu rodar essa aplicação, preciso lembrar...”
- “Guarde isso como regra recorrente.”
- “Isso deve virar memória.”

## 3. Onde salvar

Salvar a memória no domínio mais relacionado.

Exemplos conceituais:

- Memória de trabalho → `02-domains/04-work-career/memory/`
- Memória de estudo → `02-domains/03-learning/memory/`
- Memória espiritual → `02-domains/09-spirituality-values/memory/`
- Memória de saúde → `02-domains/07-health/memory/`
- Memória de finanças → `02-domains/08-finances/memory/`

## 4. Como consultar

Antes de responder sobre um domínio, projeto ou assunto, a IA deve verificar se existem memórias contextuais relacionadas.

## 5. Não criar memória sem motivo

Nem toda nota vira memória.
Uma memória deve ser recorrente, prática ou importante para futuras interações.

## 6. Não inventar memória

A IA só pode criar memória quando o usuário informar algo real ou pedir explicitamente.

## 7. Memórias podem ficar ativas, pausadas ou arquivadas

Status possíveis:

- active
- paused
- archived

## 8. Memória não substitui nota

A memória é um lembrete recorrente.
A nota guarda conteúdo normal.
A decisão guarda decisão.
A fonte guarda origem.
A wiki guarda conhecimento conectado.
