# Captura

## Objetivo

Prompts para transformar ideias rápidas e notas soltas em entradas mais claras, sem gerar conteúdo final automaticamente.

## Prompts

- [[quick-capture|Captura rápida]]
- [[transform-rough-note|Transformar nota bruta]]
- [[classify-loose-idea|Classificar ideia solta]]
- [[extract-actions-from-note|Extrair ações de uma nota]]

## Regras da categoria

- Preservar a ideia original.
- Não inventar contexto ausente.
- Quando houver dúvida, manter como captura ou pedir confirmação.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
