# Outputs

## Objetivo

Prompts para gerar documentos finais em `06-outputs/` a partir de conteúdo real e fontes preservadas.

## Prompts

- [[create-document|Criar documento]]
- [[create-study-guide|Criar guia de estudo]]
- [[create-summary|Criar resumo]]
- [[create-report|Criar relatório]]
- [[create-email-template|Criar template de e-mail]]
- [[create-prompt-pack|Criar pacote de prompts]]

## Regras da categoria

- Outputs são materiais finais.
- Fontes brutas não vão para outputs.
- Conteúdo conectado vai para wiki.
- Notas de vida vão para domains.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
