# Revisão trimestral

## Objetivo

Criar revisão trimestral estratégica do Second Brain.

## Quando usar

Use ao fim de trimestre ou ciclo importante.

## Quando não usar

Não use quando o usuário quer apenas uma limpeza pontual.

## Entrada esperada

Trimestre e áreas prioritárias.

## Regras importantes

- Não criar conteúdo simulado.
- Não inventar informações ausentes.
- Não apagar conteúdo real.
- Respeitar a estrutura do Second Brain.
- Verificar branch e `git status` quando houver alteração real.
- Não fazer merge automático.
- Basear em revisões e notas reais.
- Não criar novas áreas sem proposta aprovada.
- Destacar padrões e riscos.

## Prompt copiável

```txt
Você é um agente de IA atuando no meu Second Brain Universal.

Objetivo:
Criar revisão trimestral estratégica do Second Brain.

Contexto:
Esta tarefa deve respeitar as regras do vault, preservar fontes originais, evitar conteúdo simulado e manter a main limpa.

Entrada esperada:
Trimestre e áreas prioritárias.

Tarefa:
1. Verifique o escopo solicitado.
2. Consulte regras, manuais e memórias contextuais relevantes quando aplicável.
3. Execute apenas a tarefa descrita neste prompt.
4. Preserve conteúdo real e registre dúvidas quando houver incerteza.
5. Ao final, informe o que foi criado, atualizado, movido ou deixado pendente.

Regras:
1. Não criar conteúdo simulado.
2. Não inventar informações.
3. Não apagar conteúdo real.
4. Respeitar a estrutura do Second Brain.
5. Registrar alterações quando necessário.
6. Se houver dúvida relevante, pedir confirmação ou mover para review-needed.
7. Não fazer merge automático.

Resultado esperado:
Revisão trimestral em `07-reviews/quarterly/`.
```

## Resultado esperado

Revisão trimestral em `07-reviews/quarterly/`.

## Arquivos que podem ser afetados

- `07-reviews/quarterly/`

## Observações

Boa para ajustar direção sem bagunçar estrutura.
