# Inbox Processing

## Objetivo

Prompts para classificar e processar entradas reais de inbox sem inventar conteúdo nem apagar informação.

## Prompts

- [[process-main-inbox|Processar inbox principal]]
- [[process-domain-inbox|Processar inbox de domínio]]
- [[classify-inbox-items|Classificar itens de inbox]]
- [[clean-empty-inboxes|Limpar inboxes vazios]]

## Regras da categoria

- Processar apenas itens reais existentes.
- Não apagar informação.
- Se houver dúvida, manter no inbox ou mover para review-needed.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
