## Regras da categoria

- Use antes de qualquer tarefa operacional com risco de alterar conteúdo real.
- Priorize segurança, rastreabilidade e confirmação humana quando o escopo crescer.
- Não execute outros prompts automaticamente apenas por estarem citados.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
