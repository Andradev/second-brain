# Wiki

## Objetivo

Prompts para criar e manter conhecimento conectado em `03-wiki/` somente a partir de conteúdo real.

## Prompts

- [[create-concept-page|Criar página de conceito]]
- [[create-entity-page|Criar página de entidade]]
- [[create-synthesis-page|Criar página de síntese]]
- [[create-comparison-page|Criar página de comparação]]
- [[create-question-page|Criar página de pergunta]]
- [[update-wiki-index|Atualizar índice da wiki]]
- [[check-wiki-duplicates|Verificar duplicidades na wiki]]

## Regras da categoria

- Só criar wiki a partir de conteúdo real.
- Não criar conceitos, entidades ou sínteses vazias.
- Preservar links para notas e fontes de origem.

## Como usar

1. Escolha o prompt mais específico para a tarefa.
2. Leia as regras e preencha os placeholders.
3. Execute em agente de IA somente quando houver escopo claro.
4. Revise o resultado antes de aplicar mudanças adicionais.
