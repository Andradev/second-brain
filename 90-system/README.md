# 90-system

## O que é esta pasta

Esta pasta guarda a estrutura interna do sistema. Ela não é para notas pessoais comuns.

## Para que ela serve

Serve para manuais, templates, prompts, schemas, automações e regras que definem como o Second Brain funciona.

## Quando usar

- Quando quiser alterar como o sistema funciona.
- Quando precisar guardar um template ou prompt reutilizável.
- Quando uma regra operacional precisa ser documentada.
- Quando a IA for solicitada a melhorar a arquitetura do vault.

## Quando não usar

- Não use para notas pessoais comuns.
- Não use para fontes brutas.
- Não use para conhecimento conectado de assuntos da vida.
- Não use para outputs finais.

## O que colocar aqui

- `manuals/`: manuais operacionais.
- `templates/`: modelos de arquivos.
- `schemas/`: estruturas e padrões de metadados.
- `prompts/`: prompts importantes.
- `automations/`: ideias de automação.
- `agent-rules/`: regras específicas de agentes.
- `context-memory/`: regras, template e documentação de memórias contextuais.

## Exemplos de uso

- Exemplo conceitual: um template de nota processada.
- Exemplo conceitual: um manual de processamento de fontes.
- Exemplo conceitual: um prompt recorrente de revisão.

## Como esta pasta se conecta com o resto do sistema

`90-system/` é sobre como o sistema funciona. `02-domains/` é sobre a vida do usuário. `03-wiki/` é sobre conhecimento. `01-raw/` é sobre fontes.

## Fluxo recomendado

1. Identifique se a mudança é de sistema.
2. Escolha a subpasta correta.
3. Atualize manual, template, schema, prompt, automação ou regra.
4. Preserve regras existentes e registre mudanças relevantes.
5. Use exemplos apenas como placeholders ou texto explicativo.

## Regras importantes

- Regras operacionais continuam em `AGENTS.md`, `90-system/manuals/` e `_manual.md` dos domínios.
- Não misturar com conteúdo pessoal.
- Não transformar exemplos em notas reais.
- Alterações estruturais devem ser feitas com cuidado.

## Resumo rápido

Use `90-system/` para configurar e melhorar o próprio Second Brain.
